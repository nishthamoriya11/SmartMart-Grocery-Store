# SmartMart – Online Grocery Store


## Project Preview

A grocery product display interface featuring a clean background, organized product cards, and a responsive grid layout.

## Features

- Clean and user-friendly interface
- Product cards with images and descriptions
- Product categories and ratings
- Product pricing and discount labels
- Search input field
- Product sorting dropdown
- Product display-limit dropdown
- CSS Grid-based product layout
